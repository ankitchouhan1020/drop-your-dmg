All notable changes to Drop Your DMG are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-17

### Added

- Product-first DMG design and build skill.
- Minimal three-direction concept gate with separate shipping backgrounds and curated Finder previews.
- Product review, design, build, verification and walkthrough references.
- Three curated Notion example directions using an official public icon asset.
- Safer metadata inspection, self-contained raster preview guidance, Finder chrome allowances, an approval gate and delivery cleanup.
- Evaluation prompts covering design, installation, signing, headless builds, rendering and release verification.
- Repository validation, local-reference checks, Node tests, macOS rendering checks and GitHub Actions CI.
- npm, Pi and Agent Skills compatibility metadata.
