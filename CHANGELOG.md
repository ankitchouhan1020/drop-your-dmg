# Changelog

All notable changes to Drop Your DMG are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed

- Established a minimal design doctrine with one product cue, quiet path treatment and curated client previews.
- Replaced the fictional Orbit Notes example with three curated Notion directions using an official public icon asset.
- Added safer metadata inspection, self-contained raster preview guidance, Finder chrome allowances, an approval gate and delivery cleanup.
- Expanded evaluation and repository checks for the updated workflow and generated artifacts.

## [0.1.0] - 2026-10-17

### Added

- Product-first DMG design and build skill.
- Three-direction concept gate with separate shipping backgrounds and Finder previews.
- Product review, design, build, verification and walkthrough references.
- Orbit Notes example with three distinct generated concepts and an HTML contact sheet.
- Evaluation prompts covering design, installation, signing, headless builds and release verification.
- Repository validation, Node tests, macOS rendering checks and GitHub Actions CI.
- npm and Pi package metadata.
